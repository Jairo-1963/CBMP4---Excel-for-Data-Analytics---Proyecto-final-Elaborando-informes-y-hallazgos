# 📊 Excel for Data Analytics

Repositorio correspondiente al módulo **Excel for Data Analytics**, enfocado en el análisis de datos comerciales mediante tablas dinámicas, gráficos y presentación ejecutiva de insights.

## 🛒 Proyecto: Grocery Sales Analysis

Análisis del comportamiento de compra de clientes de una tienda de abarrotes, integrando información de ventas, productos, clientes y personal de ventas para identificar patrones y comunicar hallazgos clave.

## 🎯 Objetivo del proyecto
Analizar el desempeño comercial y los patrones de consumo utilizando herramientas de análisis y visualización en Microsoft Excel, presentando resultados de forma clara y ejecutiva.

## 📚 Actividades realizadas
- Creación de **tablas dinámicas** para análisis de ventas y productos
- Gráficos de columnas, barras, líneas y circulares
- Análisis de ventas por mes
- Identificación del top de productos más vendidos
- Distribución de clientes por país y ciudad
- Elaboración de **insights ejecutivos**

## 📈 Principales hallazgos
- Las ventas mostraron crecimiento sostenido desde enero hasta abril, con una caída en mayo.
- Estados Unidos concentra la mayor cantidad de clientes, destacando ciudades como Tulsa, New York y Miami.
- Los productos más vendidos en marzo incluyen bebidas, lácteos y productos de consumo rápido.

## 🛠️ Herramientas utilizadas
- Microsoft Excel
  - Tablas dinámicas
  - Gráficos dinámicos
- Microsoft PowerPoint
- Análisis de datos descriptivo
